📥 まとめてインポート（JSON）

研修資料や資格制度の一覧をClaudeなどの生成AIに読み取らせ、下の指示文と一緒に送るとJSONを作ってもらえます。できたJSONをここに貼り付けるか、ファイルとして保存してアップロードしてください。

Claudeへの指示文 
添付した資料の内容を読み取り、研修・資格制度のステップ一覧として登録できるように、以下のJSON配列の形式だけを出力してください（説明文やコードブロックの記号は不要です）。特定の店舗だけが対象の項目でなければ storeTags は省略するか空配列にしてください。
[
  { "title": "ステップ名（例: レジ操作の基本）", "storeTags": [] }
]

storeTagsに店舗名を入れる場合は、⚙️→🔒オーナー設定の「🏪店舗一覧」に登録済みの名前と完全に一致させてください。

🌐 表示設定

現在の店舗はホーム画面の「📍」ボタンから切り替えられます。

🔒 オーナー設定

店舗一覧・機能名称・管理者権限・Firebase接続など、お店全体に影響する設定です。通常はオーナーのみが操作してください。

🏪 店舗一覧（複数店舗運用）

複数店舗で共有運用する場合、ここで店舗名を登録します。各スタッフはホーム画面の「📍」ボタンやアプリ起動時のモーダルで、自分がいる店舗を選びます。

📋 引継ぎ項目（連絡ノートの一問一答）

連絡ノートの「引継ぎを作成する」で、スタッフに一問一答で聞かれる質問リストです。「あり」と回答された項目だけが、下の定型文を使って引継ぎ書に自動で組み込まれます。

🎓 トレーニング機能の名称

この店舗独自の資格・研修制度名に変更できます（例: 社内の正式名称）。設定は接続中のFirebaseに保存され、この店舗の全端末に共有されます。

🔐 管理者チャット設定

ここに登録したメールアドレスでログインした人だけが「管理者」として全スタッフの個別チャットを閲覧・返信できます。1行に1件入力してください。

スタッフがアプリ内で自己登録する際に必要な招待コードです。第三者に推測されにくいものに設定してください。

🔥 Firebaseデータベース設定

Firebaseコンソールでプロジェクトを作成し、Firestore Database・Authenticationの「匿名」および「メール/パスワード」プロバイダ・Storage（写真アップロード用）を用意した上で、ウェブアプリのConfigをここに貼り付けてください。通常の機能はログイン画面なしで端末が自動的に匿名認証されます（🔐管理者チャットのみ別途メールアドレスでのログインが必要です）。
